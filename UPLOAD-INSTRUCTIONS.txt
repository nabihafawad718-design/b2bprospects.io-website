B2BProspects header/brand consistency patch

This patch includes the previously prepared targeted header files, with an additional adjustment to make the B2BProspects wordmark (font size, weight, spacing, and icon size) consistent on pages using the shared header.

Upload/replace the included files at the same paths in your GitHub repository. Keep a backup first. This ZIP does not include a live-site verification. The standalone Pricing page files are not deleted automatically by GitHub ZIP upload; delete them separately only if you still want that page removed.
